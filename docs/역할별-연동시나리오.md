## 1. 운영관리자 — 리스트에서 출발하는 모든 경로

### 1-1. 회원 승인 (`/admin/users`)

|---|---|---|
| 회원명/상세 | 회원 상세 패널: 연락처·회사·상태·첨부 | ✅ |
| 〃 | 그 회원의 **매입조건 이력** | ✅ |
| 〃 | 그 회원의 **NDA 요청 이력**(매물명·상태·일자) | ✅ |
| 〃 | 그 회원의 **관심매물** | ✅ |
| 〃 | 그 회원의 **등록 매물(매각)** | ✅ |
| 〃 | 그 회원의 **문의·접수 이력** | ✅ |
| 이력 항목(매물명) | 해당 **매물 세부내역**으로 이동 | 🔧 |
| 이력 항목(매입조건) | 해당 조건의 **자동매칭 결과** | 🔧 |
| 패널에서 바로 | 승인/거절/보류 처리 | 🔧 |

| 관심 수 | 이 매물을 **관심 등록한 회원 목록** | 🔧 |

## 2. 매입 회원 — 마이페이지 연동

| 화면 | 필요한 연동 | 상태 |
|---|---|---|
| 대시보드 | 이번 주 브리핑(신규·NDA) | ✅ |
| **매입 조건** | 조건별 **자동매칭 매물 N건 + 바로 보기** ← *가장 중요* | 🔧 |
| 관심매물 | 매물 → 세부내역(NDA 승인 시) | 🔧 |
| NDA 진행 | 매물명·상태 → 세부내역 | ✅(명칭) / 🔧(이동) |
| 자동매칭 | 내 조건에 매칭된 건만 선별 | ✅ |

## 3. 매각 회원 — 마이페이지 연동

| 화면 | 필요한 연동 | 상태 |
|---|---|---|
| 내 매물 | 매물 → 세부내역 | ✅ |
| 〃 | 매칭 개사 → **어떤 매입 회원인지**(운영사 중개 원칙상 익명 요약) | 🔧 |
| 〃 | NDA 요청자 표시(이름·상태) | ✅ |
| 〃 | 관심 수 | ✅ |
| 주간 요약 | 반응 집계 | ✅ |

## 4. 운영 파트너
관리자와 동일 경로 **전부 열람 가능**, 처리 버튼만 비활성. | ✅

---

## 5. 이번 작업 범위 (필수만)

1. **매입 조건 → 자동매칭 결과** (마이페이지 + 관리자) — 조건별 매칭 매물 수와 목록
2. **매물 → 반응 상세**: 매칭 매입사 / NDA 요청자 / 관심 회원 목록 (관리자)
3. **회원 패널 내 이력 → 해당 매물·조건으로 이동**
4. **NDA 화면에 요청자 매입조건 요약** 표시
5. **접수함 → 접수 회원 상세** 연결

보류(⏸): 매각 회원에게 매입 회원 실명 노출 — 중개 원칙상 운영사만 식별, 매각 회원에게는 건수·조건 요약만.
