# 전 역할 테스트 시나리오 & 개발범위 (2026-08-19)

> 대상: 회원가입 · 로그인 · 서비스 이용 · 마이페이지 × **매입 회원 / 매각 회원 / 겸용 / 운영관리자 / 운영 파트너**
> 방식: 시나리오를 **케이스 조합으로 정의**하고(총 1,000+ 조합), 라운드마다 실계정으로 실행 → 실패 건을 결함으로 등록 → 수정 → 회귀.
> 원칙: 시나리오 1건 = "누가 / 어떤 상태에서 / 무엇을 하면 / 무엇이 보여야 하는가" 한 줄로 검증 가능해야 한다.

---

## 1. 시나리오 생성 공식 (1,000건 도출 근거)

```
시나리오 = 페르소나(5) × 회원상태(6) × 기능(≈14) × 데이터조건(≈2.5)
        = 5 × 6 × 14 × 2.5 ≈ 1,050
```

| 축 | 값 |
|---|---|
| 페르소나 (5) | 매입(법인) · 매입(개인) · 매각 · 겸용 · 운영(관리자/파트너) |
| 회원상태 (6) | 비로그인 · 승인대기 · 보류 · 활성 · 거절 · 차단/탈퇴 |
| 기능 (14) | 가입 · 로그인/로그아웃 · 비번재설정 · 자동매칭 열람 · 검색/필터 · 관심 · NDA 제출 · 세부내역 열람 · 매각의뢰 · 매입조건 CRUD · 내 매물 상태변경 · 진행종료 요청 · 알림/수신설정 · 설정(프로필/비번) |
| 데이터조건 (2.5) | 데이터 없음(빈 상태) · 정상 · 경계값(다수/장문/비정상 입력) |

운영 전용 기능(회원 승인·매각의뢰 검토·NDA 승인·콘텐츠 CRUD·접수함·전환)은 위 조합에 **운영자 축으로 별도 200여 건** 포함.

## 2. 라운드 구성 (총 1,000회 = 20라운드 × 50케이스)

| 라운드 | 범위 | 핵심 확인 |
|---|---|---|
| R1–R2 | 가입 (5 페르소나 × 정상/에러/중복/첨부) | 역할 분기, 첨부 업로드, 승인대기 진입 |
| R3–R4 | 로그인·세션 (6 상태 × 5 페르소나) | 상태별 접근 차단, 로그아웃, 비번 재설정 |
| R5–R7 | 매입 서비스 이용 | 자동매칭 열람 게이팅, 검색/필터, 관심(서버 저장), NDA 제출 |
| R8–R9 | NDA 2단계 | 제출 → 검토 → 승인/거절 → 열람권, 4필드 비공개 |
| R10–R11 | 매각 흐름 | 매각의뢰 접수 → 매물 전환(seller_id) → 상태 변경 → 진행종료 |
| R12 | 겸용 회원 | 메뉴 합집합, 요약 2종 병행, 양쪽 알림 |
| R13–R14 | 마이페이지 전 화면 | 빈 상태·다건·검색·페이지네이션·설정 저장 |
| R15–R16 | 운영관리자 | 승인/거절/보류/차단/복구, 매각의뢰 검토, NDA 승인, 콘텐츠 CRUD(이미지 첨부 포함) |
| R17 | 운영 파트너 | 전 화면 열람 전용(입력 차단) |
| R18 | 알림 | 다이제스트 발송, 수신설정 존중, 인앱 표시 |
| R19 | 화면 품질 | 가로 스크롤 0, 정렬, 콘솔 오류 0, 모바일 |
| R20 | 회귀 | 앞선 수정이 다른 기능을 깨지 않았는지 전수 재확인 |

## 3. 페르소나별 대표 시나리오 (각 축의 샘플 — 실행 시 상태 6종으로 확장)

### 3-1. 매입 회원 (법인/개인)
1. 가입 시 법인 선택 → 사업자번호 필수 검증 / 개인 선택 → 투자규모 선택
2. 가입 완료 → **매입조건 등록 화면으로 이동** (서비스와 동일 폼)
3. 승인대기 상태로 자동매칭 접근 → 안내 표시
4. 활성 후 자동매칭 열람 → 매칭 조건 기준 선별 노출
5. 검색(동 이름)·필터(지역/유형/금액)·정렬·카드/리스트 전환
6. 관심 등록 → **다른 기기·재로그인 후에도 유지**(서버 저장)
7. NDA 제출 → 상태 '운영사 검토' → 매각 회원·관리자에 알림
8. 승인 전 세부내역 접근 → 잠금 안내 / 승인 후 → 40필드 열람, **채권기관·담당자·직책·연락처 비공개**
9. 매입조건 등록·수정·삭제 → 마이페이지 목록에 **본인 것만**
10. 일일 다이제스트 수신 → `?alert=` 링크로 신규 구간만 표시
11. 수신 설정 OFF → 다음 발송 제외
12. 설정에서 프로필·비밀번호 변경

### 3-2. 매각 회원
1. 가입(기관 유형·사업자번호) → 승인대기
2. 매각의뢰 접수(첨부 포함) → 접수함 티켓 생성, 실패 시 오류 표시(가짜 성공 금지)
3. 관리자 **매물 전환** → 내 매물에 등장(seller_id 연결)
4. 내 매물: 매물명·주소 한 줄, 상태 3종 변경, 매칭 개사, 반응(관심·NDA·상담)
5. NDA 요청 도착 알림 → 내 매물에서 요청자·상태 확인
6. 진행종료 요청 → 접수함 접수 → 운영 승인
7. 주간 리포트 수신 → 내 매물 주간 요약과 동일 수치

### 3-3. 겸용 회원
1. 관리자 역할 겸용 저장 → **다음 진입 시 메뉴 합집합**
2. 대시보드에 **매각 주간 요약 + 매입 브리핑 2블록**
3. 내 매물과 매입조건을 한 세션에서 동시 운용
4. 알림 2종(일일·주간) 모두 수신

### 3-4. 운영관리자
1. 회원 승인: 승인대기/보류 → **[승인][거절]**, 활성 → **[차단]**, 거절/탈퇴 → **[승인(복구)]**
2. 회원 상세: 첨부 뷰어 · 매입조건 · NDA · 관심 · 매물 · 문의 이력
3. **리스트 → 회원 직결**: 매입조건 담당자 / 매각의뢰 매각 회원 / NDA 요청자 클릭
4. 매각의뢰 검토 승인·거절, 세부내역 40필드 수정·저장·엑셀·인쇄
5. NDA 승인/거절 → 매입 회원 열람권·알림
6. 콘텐츠: 하이라이트·언론보도·히어로 **이미지 URL + 파일 첨부**, 메인 지표
7. 접수함: 답변·상태 변경·매물 전환
8. 대시보드 카운트 → 클릭 이동

### 3-5. 운영 파트너
1. 관리자 화면 전체 열람 가능, **입력·버튼 비활성**
2. 열람 전용 배너 표시, 마이페이지는 열람 링크만

## 4. 결함 등록 규칙

| 등급 | 정의 | 처리 |
|---|---|---|
| 🔴 Blocker | 로그인·가입 불가, 데이터 미저장, 권한 누출 | 즉시 수정 후 재배포 |
| 🟠 Major | 기능은 되나 결과가 틀림(집계·필터·연결 오류) | 해당 라운드 내 수정 |
| 🟡 Minor | 표기·정렬·문구 | 라운드 묶어서 수정 |

**"조용한 실패" 금지 원칙**: 실패한 동작을 성공처럼 보여주면 등급은 무조건 🔴.

## 5. 개발범위 — 순차 리스트 (남은 작업)

> 앞선 20라운드에서 완료된 항목은 §6에 정리. 아래는 **지금부터의 개발 대상**.

### 1순위 — 프로세스 완결 (필수)
| # | 항목 | 규모 | 비고 |
|---|---|---|---|
| 1 | 이메일 실발송 연결(SMTP/Resend) + 발송 로그 | S | 계정 필요 — 현재 인앱만 동작 |
| 2 | 매각의뢰 접수 → 매물 전환 시 **입력 폼**(주소·유형·금액 지정) | M | 현재 기본값 생성 |
| 3 | 진행종료를 매물 상태(종료요청중/종료)로 승격 | M | 현재 티켓으로만 |
| 4 | 회원 상태 차단/탈퇴 시 **로그인 차단 실동작** 검증·보강 | S | locked_until 적용 확인 |
| 5 | 매물 세부내역 40필드 **매각 회원 편집 권한** 분리 | M | 현재 운영자와 동일 폼 |

### 2순위 — 운영 편의
| # | 항목 | 규모 |
|---|---|---|
| 6 | 회원 상세에서 바로 승인/거절/보류 처리(패널 내 액션) | S |
| 7 | 매입조건 ↔ 매물 매칭 결과 상세(어떤 조건이 걸렸는지) | M |
| 8 | 접수함 답변 템플릿 · 처리 이력 타임라인 | M |
| 9 | 관리자 대시보드 기간 필터(오늘/주/월) | S |
| 10 | 엑셀 내보내기 전 화면 통일(회원·매물·조건·NDA) | S |

### 3순위 — 품질·확장
| # | 항목 | 규모 |
|---|---|---|
| 11 | 첨부 파일 유형 확장(PDF 등기부·감정평가서) + 뷰어 | M |
| 12 | 매물 이미지 다중 업로드(현재 URL 1장) | M |
| 13 | 알림 발송 이력 화면(누구에게 언제 무엇을) | M |
| 14 | 감사 로그(관리자 행위 기록) | M |
| 15 | 모바일 전용 레이아웃 최적화(표 → 카드) | L |

규모: S(0.5일) · M(1~2일) · L(3일+)

## 6. 완료된 범위 (1~20라운드 누적)

- 인증: 로그인 500 장애·가입 트리거 장애·프로덕션 dev계정 함정 제거
- 회원 Key 연동: NDA·관심·매입조건·매물·티켓 **100% user_id 연결**, 리스트→회원 패널 직결
- 마이페이지: 역할별 화면 정리(레거시 15경로 제거), 겸용 합집합·요약 2종
- 관리자: 승인 상태 기계, 접수함 전환, 콘텐츠 이미지 첨부, 레거시 21경로 제거
- 알림: 인앱 이벤트, 일일/주간 다이제스트(RPC), 수신설정 연동
- 품질: 가로 스크롤 재설계(표 폭 −35%), 하이드레이션 오류 제거, 표 밀도 통일
