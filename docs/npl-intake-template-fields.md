# NPL 상세내역 표준 양식 — 전체 필드 명세 (SSoT)

> 출처: 부실채권(NPL) 상세내역 작성양식 (대구중앙로신협 실제 접수본, 2026-08)
> 정책: **매수자 리스트에는 제한 필드만 노출** (관리번호·등록일·지역·주소 동단위·유형·토지/건물면적·감정가·채권잔액·협의가).
> **관리자 + 매각의뢰자(본인 건)는 아래 전체 필드 열람** — 관리자 대시보드 상세 화면 기준.

## 접근 정책
- **매수자(리스트)**: 제한 9필드 + 사진 + NDA 요청 버튼만
- **NDA 체결 매수자**: 전체 필드 + 세부주소 + 기관 실명
- **매각의뢰자**: 본인 등록 건 전체 필드 열람·수정·삭제 (`/my/seller`)
- **관리자**: 전 건 전체 필드 열람 (`/admin/listings`)
