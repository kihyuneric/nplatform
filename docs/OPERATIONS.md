## 운영 루프 — 하루 5분

관리자(`/admin`) 대시보드의 숫자 순서 그대로:

```
① 접수함        새 매각의뢰·1:1 문의 확인 → 상태(접수→처리중→완료) 클릭
② 회원 승인     PENDING 회원 승인/거절 (승인해야 계정 활성화)
③ 매물 관리     접수된 의뢰 → 직접 등록(비식별화) · 수정 · 삭제
④ 매수 수요     매입조건 확인 (수정·삭제 가능) — 실매칭 엔진이 자동 대조
⑤ 딜 진행      물건별 단계 클릭: 관심등록 → 실사진행 → 가격협의 → 최종계약
⑥ 분석·마케팅   물건별 8채널 체크리스트 체크 + 상담 수 입력
⑦ 메인 지표     열람 가능한 NPL · 신규 건수 수기 갱신 (주 1회)
```

⑤⑥⑦에서 입력한 모든 것은 **매각사 대시보드(/my/seller)에 실시간 공유**된다.

## 화면 지도

| 사용자 | 화면 | 하는 일 |
|---|---|---|
| 방문자 | 메인 → NPL 리스트 (10건 프리뷰) | 제한 12필드만 열람, 하트(관심)·NDA 전자서명 |
| 매각사 | NPL 매각의뢰 (파일 첨부) → /my/seller | 접수 후 매칭 수·마케팅·관심·NDA·상담·딜 단계 확인 |
| 매입사·투자자 | 매입조건 등록 (우선순위 다중) → /my/demands | 조건 맞는 딜만 공개됨 |
| 관리자 | /admin (8메뉴) | 위 운영 루프 |

## 자동으로 도는 것 (손대지 않아도 됨)

- **실매칭 엔진**: 매입조건(지역·유형·금액대) ↔ 활성 매물 자동 대조 → 매각사 "매칭 매입사 수"
- **관심·NDA 집계**: 리스트의 하트·NDA 서명이 운영/매각사 대시보드에 자동 반영
- **10건 게이팅**: 매칭 조건 없는 방문자에겐 10건 + "매입조건 등록" 유도 배너
